# Repo rules

Static marketing site for vFactor Solutions, served from `docs/` via GitHub Pages.

- Keep all published site assets inside `docs/` and source-only originals (like `assets-src/founder.png`) outside `docs/` so multi-megabyte masters are not deployed.
- Keep `docs/CNAME` (`vfactorsolutions.com`) and `docs/.nojekyll` intact.
- Preserve existing accessibility attributes, semantic heading hierarchy, and theme/consent behavior across all HTML pages.
